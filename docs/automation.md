# Автоматизация

ByeZapret можно включать, выключать и менять стратегию из других приложений и скриптов. Для
этого есть активность `ToggleActivity`: она принимает стратегию и флаги в extras.

## Как вызвать

Активность не имеет `intent-filter`, поэтому её вызывают только явным компонентом: нужны
пакет и класс. Для тестовых сборок пакет — `io.github.zapretdroid.debug`:

```
io.github.zapretdroid.debug/io.github.zapretdroid.classic.activities.ToggleActivity
```

Пример через `adb` (тот же вызов можно сделать из Tasker или любого приложения с `Intent`):

```sh
adb shell am start -n io.github.zapretdroid.debug/io.github.zapretdroid.classic.activities.ToggleActivity \
  --es strategy "-o1 -a1 -r-5+se" --ez only_start true
```

## Extras

| Extra | Тип | Что делает |
|---|---|---|
| `strategy` | строка | Записывает стратегию (командную строку) как текущую |
| `only_start` | логический | Запускает VPN, если он выключен; если уже работает, ничего не делает |
| `only_stop` | логический | Останавливает VPN, если он работает; если выключен, ничего не делает |
| `only_update` | логический | Только записывает `strategy`, не трогая VPN |

Без флагов активность переключает VPN:

- VPN выключен — запускает его;
- VPN работает, и `strategy` не передана или совпадает с текущей — останавливает его;
- VPN работает, и `strategy` отличается от текущей — перезапускает его с новой стратегией.

Если передано несколько флагов, действует первый по порядку: `only_update`, затем
`only_start`, затем `only_stop`. Стратегия при этом записывается до выбора действия, поэтому
`strategy` вместе с `only_start` сохраняет стратегию и запускает VPN с ней.

## Ограничения стратегии

Стратегия из чужого приложения проверяется, и отклоняются:

- любой аргумент с `/` — пути к файлам (`-l /data/...`, `-H /...`, `--fake-data /...`);
- опции, открывающие прокси наружу или меняющие слушающий адрес: `-i`/`--ip`,
  `-p`/`--port` (в том числе `-p1080`), `-E`/`--transparent`, `-D`/`--daemon`,
  `-w`/`--pidfile`.

Допустимы `{fake:имя}` и `{list:имя}`. Отклонённая стратегия пишется в logcat, а действие
выполняется со старой стратегией.

## Чего не будет

- **VPN не запустится без согласия.** В режиме VPN запуск требует, чтобы пользователь уже
  выдал разрешение на VPN в самом приложении (системный запрос). Без него `only_start` и
  переключение молча ничего не делают.
- **Ответа нет.** Активность сразу закрывается и ничего не возвращает. Её записи идут
  в logcat с тегом `ToggleServiceActivity`, в журнал приложения они не попадают.

## Безопасность

Активность экспортирована (`exported="true"`) и не защищена разрешением. Значит, любое
приложение на телефоне может включить, выключить и переписать стратегию, в том числе
приложение, которому вы не доверяете. Ограничения стратегии от путей и слушающих адресов
защищают данные и прокси, но сам вызов они не ограничивают. В версии 0.11.0 других
защит нет. Устанавливайте только нужные приложения и не давайте лишних разрешений.
