# Стратегии

Стратегия — строка аргументов движка ByeDPI. ByeZapret добавляет к ней свои: фейковые
нагрузки `{fake:…}`, хост-листы `{list:…}`, маркеры позиций zapret и модификации HTTP.
Ниже — пресеты, синтаксис, группы по сервисам и сборка мультистратегии вручную.

Стратегия задаётся на главном экране (карточка стратегии) или в *Настройки → командная
строка*. Смена на лету переподключает VPN.

## Пресеты

| Пресет | Что делает |
|---|---|
| Адаптивная | Disorder; если соединение похоже на блокировку, переключается на разбиение TLS-записей |
| Disorder | Первый байт отправляется не по порядку |
| Разбиение по SNI | Разбивает запрос внутри имени домена |
| OOB в SNI | Вставляет внеполосный байт в имя домена |
| TLS-записи | Делит ClientHello на две TLS-записи; при сбое переходит на disorder |
| Фейковый пакет | Сначала отправляет обманку с низким TTL; TTL может понадобиться подобрать под провайдера |
| TCP + QUIC/UDP | Disorder и TLS-записи для TCP; фейковый QUIC Initial перед первыми 4 датаграммами UDP 443 (YouTube) |
| Discord и звонки | TCP как выше; для UDP фейки под протокол потока (голос Discord, STUN, QUIC), TTL 4, перед первыми 4 датаграммами |
| Как в ByeByeDPI | Командная строка ByeByeDPI по умолчанию |
| Своя | Собственная командная строка |

## Синтаксис: основное

Аргументы движка (полный список и подробности — в [UPSTREAM.md](../app/src/main/cpp/engine/UPSTREAM.md)):

| Опция | Смысл |
|---|---|
| `-s`, `--split <pos>` | Разбить запрос в позиции |
| `-d`, `--disorder <pos>` | Разбить и отправить в обратном порядке |
| `-o`, `--oob <pos>` | Разбить и отправить как OOB-данные |
| `-q`, `--disoob <pos>` | Разбить, в обратном порядке, как OOB |
| `-f`, `--fake <pos>` | Разбить и послать фейковый пакет перед настоящим |
| `-r`, `--tlsrec <pos>` | Сделать TLS-запись в позиции |
| `-t`, `--ttl <n>` | TTL фейковых пакетов (по умолчанию 8) |
| `-a`, `--udp-fake <n>` | Число фейковых UDP-датаграмм (по умолчанию 0) |
| `-n`, `--fake-sni <str>` | Подменить SNI в фейке (`?` буква, `#` цифра, `*` буква или цифра) |
| `-l`, `--fake-data <file\|:str>` | Свой фейковый пакет |
| `-M`, `--mod-http <h,d,r>` | Модификации HTTP |
| `-K`, `--proto <t,h,u,i>` | Какие протоколы трогать: tls, http, udp, ipv4 |
| `-V`, `--pf <порты>` | Диапазон портов |
| `-H`, `--hosts <file\|:str>` | Только перечисленные хосты |
| `-A`, `--auto <t,r,s,n,c>` | Начать новую группу; буквы — условия перехода |
| `-T`, `--timeout <s>` | Таймаут ответа, после которого срабатывает автопереход |
| `--mss <n>` | TCP MSS исходящих соединений |

**Позиция** записывается как `смещение[:повторы:пропуск][+флаги]`. Флаги: `+s` — от начала
SNI, `+h` — от Host, `+n` — от null, `+e` — от конца, `+m` — от середины.

**Маркеры zapret** вместо числа: `method`, `host`, `endhost`, `sld`, `midsld`, `endsld`,
`sniext`. Например, `--split midsld`, `--tlsrec sniext+1`, `--disorder host+1`.

**Модификации `-M`** (из tpws): `hostcase`, `hostspell=`, `hostdot`, `hosttab`,
`hostnospace`, `hostpad=N`, `methodspace`, `methodeol`, `unixeol`.

Пример из файла стратегий приложения: `--disorder 1 --tlsrec sniext+1`. Другой:
`--oob 1 --split midsld --tlsrec sniext+1`.

Для `-A` буквы — условия, по которым группа переключается на следующую стратегию:
`t` — сброс соединения (TORST), `r` — редирект на страницу заглушки, `s` — ошибка TLS,
`c` — соединение не установилось. `n` здесь ничего не добавляет. `-A` без букв — просто
новая группа без условий.

## Группы и хост-листы

`-H` ограничивает стратегию списком хостов. Он принимает:

- строку в кавычках: `-H:"youtube.com googlevideo.com ytimg.com"`;
- файл или список приложения: `--hosts {list:youtube}`.

Хост-лист — файл с доменами, по одному в строке, в формате zapret (импорт, gzip или
загрузка по ссылке в *Списках доменов*).

Группы разделяются `-A`. Опции до разделителя относятся к группе, которая перед ним, а
опции после — к следующей. Группа без `-H` применяется ко всем хостам, поэтому её ставят
последней.

## Мультистратегия вручную

Мультистратегия даёт разным сервисам разные стратегии в одной команде: например, YouTube
с одной, Discord с другой, а всё остальное с главной.

Порядок сборки:

1. **Подготовьте хост-листы.** Для каждого сервиса создайте список в *Списках доменов*
   (например, `youtube` и `discord`) или перечислите домены прямо в `-H:"…"`.
2. **Напишите группы.** Каждая группа — `--hosts {list:имя}` (или `-H:"…"`) и её аргументы.
3. **Разделите группы** `--auto=none` (то же, что `-An`).
4. **Последней добавьте главную стратегию** без `-H`: она обработает всё, что не попало в
   группы выше.

Пример:

```
--hosts {list:youtube} --disorder 1 --tlsrec sniext+1 --auto=none --hosts {list:discord} --udp-fake 1 --auto=none -o1 -a1 -r-5+se
```

Здесь YouTube получает disorder с TLS-записью, Discord — фейковые UDP-датаграммы, остальные
сайты идут по главной стратегии `-o1 -a1 -r-5+se`.

Вставьте команду в *Настройки → командная строка*, включите VPN и проверьте сайты. Стратегия,
введённая в редакторе, сама запоминается в истории стратегий на главном экране.

**Автоматическая сборка.** Сборщик мультистратегии в [глубокой проверке](strategy-testing.md)
делает то же самое из результатов проверки: берёт до пяти дополнительных стратегий, каждой
отдаёт домены, на которых она сработала, и сохраняет их как списки `multi_<время>_N`. Ручная
сборка нужна, когда результаты проверки не охватывают нужные сайты или вы хотите свой набор.

## Подстановки

- `{fake:имя}` — фейковая нагрузка из встроенного набора (кнопка «Вставить фейковую
  нагрузку»). Например, `--udp-proto-fake quic:{fake:quic_initial_www_google_com.bin}`.
- `{list:имя}` — хост-лист из *Списков доменов*.
- `{sni}` в стратегиях ByeByeDPI заменяется значением из настройки «SNI для фейковых
  пакетов» при подборе.

## Что проверить после изменения

- Сайт из группы открывается через VPN.
- Сайт вне групп открывается по главной стратегии.
- Если сломалось, проверьте, не стоит ли группа без `-H` раньше групп с `-H`.
