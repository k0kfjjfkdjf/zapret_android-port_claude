# Быстрый старт

Пошаговое включение ByeZapret. Остальные страницы: [стратегии](strategies.md),
[подбор стратегии](strategy-testing.md), [решение проблем](troubleshooting.md),
[автоматизация](automation.md), [приватность](privacy.md).

<a id="1-выбрать-и-установить-apk"></a>
<details>
<summary><b>1. Выбрать и установить APK</b></summary>

Сборки лежат в [релизах](https://github.com/k0kfjjfkdjf/zapret_android-port_claude/releases).
Их два вида: **стабильная** — обычный релиз, файлы `byezapret-*.apk`, приложение
`io.github.zapretdroid`; **тестовая** — пре-релиз, файлы `zapretdroid-*.apk`, приложение
`io.github.zapretdroid.debug` (новые функции раньше, но и ошибки тоже). Это два разных
приложения: одно не встанет поверх другого, можно держать оба. Обновление из приложения
предлагает каждому только его канал.

Какой файл взять:

- `*-universal.apk` — подходит для любого телефона, если не знаете архитектуру;
- `*-arm64-v8a.apk` — большинство современных телефонов, меньше по размеру;
- `armeabi-v7a` — старые 32-битные телефоны; `x86`, `x86_64` — эмуляторы.

Нужен Android 7.0 или новее. Контрольные суммы — в `SHA256SUMS.txt` того же релиза.

Тестовые сборки старше 0.9.3 подписаны другим ключом: их нужно удалить перед установкой новой
версии. Начиная с 0.9.3 обновление ставится поверх без потери настроек. Перейти с тестовой на
стабильную: экспорт настроек в тестовой (*Настройки → Резервная копия*), установка стабильной,
импорт.

</details>

<a id="2-включить"></a>
<details>
<summary><b>2. Включить</b></summary>

1. Откройте ByeZapret и нажмите кнопку включения.
2. Android покажет запрос на VPN-соединение — разрешите его. Это локальный VPN: он нужен
   только чтобы перехватить соединения. Трафик не уходит на сервер проекта.
3. Пока приложение работает, Android показывает значок VPN в строке состояния. Уведомление
   содержит кнопку остановки и паузы.

Если запрос VPN не появился, а приложение не включается, откройте «Проверку функций» в
настройках: она покажет, какое разрешение не выдано.

</details>

<a id="3-проверить"></a>
<details>
<summary><b>3. Проверить</b></summary>

Откройте сайт или приложение, которые раньше не работали. Если заработало — готово.

Если нет:

- смените стратегию на главном экране (пресеты, закреплённые и история);
- или запустите [подбор стратегии](strategy-testing.md) — он сам перебирает стратегии
  на выбранных сайтах;
- если не помогает, см. [решение проблем](troubleshooting.md).

Стратегия по умолчанию — пресет «Адаптивная»: disorder, при блокировке — разбиение
TLS-записей, затем фейки. У разных провайдеров работают разные стратегии, поэтому, если эта
не помогла, подберите свою.

</details>

<a id="4-настроить-охват-по-желанию"></a>
<details>
<summary><b>4. Настроить охват (по желанию)</b></summary>

<details>
<summary><b>Приложения</b></summary>

В *Настройки → Какие приложения идут через VPN* — раздельное
туннелирование; там же для каждого приложения можно выбрать «через прокси», «напрямую» или
свою стратегию.

</details>

<details>
<summary><b>DNS</b></summary>

Обычный DNS-запрос провайдер может подменить, и тогда сайт не откроется даже
при правильной стратегии. В *Настройки → DNS и DNSCrypt* можно включить шифрованный DNS
(DNS over HTTPS, DNS over TLS или DNSCrypt со списком серверов), а в *Блокировка рекламы и
вредоносных сайтов* — блокировку по спискам.

</details>

<details>
<summary><b>Сайты через прокси</b></summary>

Для сервисов, которые отказывают российским адресам сами (ChatGPT,
Gemini, Claude и другие), обход DPI не поможет. Для них есть Tor (Orbot или InviZible Pro в
режиме прокси) и свой SOCKS5-прокси: *Настройки → Сайты через прокси*.

</details>

</details>

<a id="5-обновления"></a>
<details>
<summary><b>5. Обновления</b></summary>

Приложение раз в 12 часов проверяет релизы на GitHub. Новую версию можно поставить кнопкой
в настройках: приложение скачает APK под архитектуру телефона, проверит SHA-256 и откроет
системный установщик. Подробнее — в [приватности](privacy.md).

</details>

<a id="режим-прокси"></a>
<details>
<summary><b>Режим прокси</b></summary>

Вместо VPN можно включить режим прокси, он есть в интерфейсе ByeByeDPI (*Настройки →
Интерфейс ByeByeDPI*). Тогда приложение поднимает SOCKS5-прокси на адресе из настроек
ByeByeDPI (по умолчанию `127.0.0.1:1080`), и нужные программы настраиваются на него вручную. Туннеля в этом режиме нет, поэтому раздельное туннелирование
по приложениям к нему не относится.

</details>
