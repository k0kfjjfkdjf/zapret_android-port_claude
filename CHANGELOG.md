# История изменений

Раздел каждой версии автоматически попадает в описание её релиза на GitHub.

## 0.11.6

- Самопроверка «Telegram through the proxy» стала честной. Для групп с прокси движок сразу
  отвечает «подключено», а к прокси подключается только на первых данных. Поэтому прежняя
  проверка (OK за 4 мс) подтверждала лишь то, что движок принял соединение. Теперь она
  отправляет HTTP-запрос серверу Telegram (порт 80) и ждёт его ответа через прокси.
- Проверено на телефоне: в 0.11.5 нет FAIL, проверки стратегий Discord запускаются все.

## 0.11.5

- Самопроверка «Telegram through the proxy» подключалась к движку по `::1`, а движок слушает
  `127.0.0.1`. Из-за этого проверка всегда давала WARN, хотя сама функция в порядке.
- Проверка стратегий больше не запускает следующий движок, пока предыдущий не остановился.
  После долгих проверок на телефоне это иногда давало FAIL «engine did not start».
- Проверено на телефоне: прокси InviZible Pro отвечает, chatgpt.com открывается через прокси.
- Проверено на телефоне: Telegram с ByeZapret работает через Tor из InviZible Pro. Если Tor
  остановить, сообщения перестают отправляться, то есть Telegram действительно идёт через прокси.

## 0.11.4

- **Быстрый первый ответ DNS в режиме DNSCrypt.** При запуске VPN все выбранные серверы
  измеряются одним запросом, как это делает dnscrypt-proxy. Первым сразу спрашивается
  самый быстрый из отвечающих. Раньше первые запросы шли по порядку списка, и на телефоне
  первый ответ занимал 4,7 с. В журнал пишется, сколько серверов отвечает и какие быстрее всех.
- **Telegram через прокси.** Переключатель в *Настройки → Сайты через прокси*. Приложение
  Telegram подключается к своим IP без имён, поэтому через прокси оно идёт по диапазонам адресов
  Telegram, а его сайты по списку `telegram`. Работает через Tor. Звонкам нужен прокси с UDP.
  Самопроверка подключается к серверу Telegram через прокси.
- **Исправлены списки IP (`--ipset`) в движке.** На телефонах адреса IPv4 приходят в виде
  IPv6 (`::ffff:…`) и не совпадали ни с одной записью списка. Это та же причина, что у
  ошибки DNS в 0.11.1.
- Проверено на телефоне: после 0.11.3 строка «encrypted DNS through the engine» снова OK.

## 0.11.3

- **Ответ резолвера больше не ждёт медленный или сломанный сервер.** Если выбранный сервер
  не ответил за 0,8 с, параллельно спрашивается следующий, и берётся первый ответ.
  В 0.11.2 первым в списке стоял неработающий сервер, и резолвер не укладывался в 5 секунд
  (FAIL «encrypted DNS through the engine»).
- На ошибочный ответ сервера (HTTP 400, 505 и другие) запрос больше не повторяется три раза.

## 0.11.2

- Проверено на телефоне: после 0.11.1 зашифрованный DNS через VPN работает. Самопроверка
  показывает ответ от `10.10.10.53`.
- Если сервер требует SNI (HTTP 421, cloudflare из списка), теперь хватает попыток, чтобы
  повторить запрос с SNI.
- Ответы HTTP 505 и 400 от DoH-серверов (Quad9 DoH, BlahDNS, bortzmeyer, CIRA, a-and-a)
  объясняются в самопроверке: такие серверы, вероятно, работают только по HTTP/2, которого пока
  нет. Для них используйте DoT или другой сервер. Поддержка HTTP/2 стоит в плане.
- В самопроверке строка о DNS тестера больше не перечисляет все ссылки на серверы.

## 0.11.1

- **Исправлен зашифрованный DNS в VPN** (DoH, DoT, DNSCrypt). На телефонах движок хранит
  UDP-адреса в виде IPv6 (`::ffff:10.10.10.53`), а адрес перенаправления DNS сравнивался как
  IPv4. Из-за этого запросы к DNS VPN не доходили до резолвера приложения, и самопроверка
  показывала FAIL «encrypted DNS through the engine».
- **DoH-серверы без длины ответа** (Quad9 DoH, a-and-a, CIRA, BlahDNS и другие) раньше
  отбрасывались с ошибкой «HTTP answer without length». Теперь ответ читается до закрытия
  соединения.
- Если сервер отвечает HTTP 421 (cloudflare из списка), запрос повторяется с SNI.
- Тестер и самопроверка в режиме DNSCrypt перебирают выбранные серверы, а не берут только
  первый.
- Рекомендация DNS в самопроверке учитывает режим DNSCrypt и правильно называет раздел
  настроек.
- В журнале при выборе серверов пишутся только добавленные и убранные, а не весь список.

## 0.11.0

- **Модуль Tor.** Tor без второго приложения. Отдельный APK «ByeZapret Tor» (около 15 МБ на
  архитектуру), внутри Tor 0.4.9.14 от Guardian Project и транспорты мостов obfs4, meek,
  WebTunnel и Snowflake (IPtProxy).
- Модуль скачивается кнопкой в *Настройки → Сайты через прокси → Модуль Tor* и сверяется
  с `SHA256SUMS.txt`. Используется, только если подписан тем же ключом, что и приложение.
  Управлять им может только ByeZapret.
- Tor модуля запускается и останавливается вместе с VPN. Он слушает SOCKS5 по адресу прокси
  (по умолчанию `127.0.0.1:9050`), сам модуль работает вне VPN.
- Мосты: без мостов, встроенные из Tor Browser (Snowflake, obfs4, WebTunnel, meek) или свои
  строки. Проценты подключения и ошибки Tor видны в настройках и в журнале.
- Переключатель «Использовать модуль Tor»: модуль или Orbot/InviZible.

## 0.10.0

- **DNSCrypt.** Новый режим DNS со своим клиентом DNSCrypt v2:
  - сертификат сервера проверяется по ключу провайдера;
  - шифрование XSalsa20 или XChaCha20;
  - если ответ по UDP усечён, запрос повторяется по TCP.
- **Публичный список серверов** (778 серверов DNSCrypt и DoH, тот же, что у dnscrypt-proxy и
  InviZible Pro):
  - список используется, только если сходится его подпись minisign;
  - обновляется раз в 3 дня;
  - поиск и фильтры: DNSCrypt, DoH, DNSSEC, без журналов, без фильтрации, IPv6;
  - проверка скорости серверов;
  - можно выбрать несколько серверов: первым спрашивается самый быстрый из отвечающих;
  - свой сервер добавляется по ссылке `sdns://`.
- Самопроверка проверяет каждый выбранный сервер.

## 0.9.9

- **Блокировка рекламы, вредоносных и «взрослых» сайтов** в режимах зашифрованного DNS:
  - списки HaGeZi (Multi NORMAL, Threat Intelligence mini, NSFW), скачиваются по кнопке и
    обновляются раз в 3 дня;
  - домен блокируется вместе с поддоменами;
  - свои списки `dns-block` и `dns-allow`.
- Новые фильтрующие серверы: AdGuard Family, Cloudflare Security и Cloudflare Family. При сбое
  сервер заменяется только сервером с такой же фильтрацией.

## 0.9.8

- **Свой прокси с UDP.** Раздел «Сайты через прокси (Tor или свой)»: свой SOCKS5 (sing-box,
  Xray, NekoBox). Переключатель «UDP тоже через прокси» пускает через него QUIC и звонки
  (SOCKS5 UDP ASSOCIATE).
- Самопроверка проверяет, умеет ли прокси передавать UDP.
- Адрес прокси теперь только `IP:порт`: с именем хоста VPN не запускался.
